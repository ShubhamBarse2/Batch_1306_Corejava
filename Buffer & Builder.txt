StringBuilder & StringBuffer -> (Mutable(can be changed)) : 

this both are the inbuild classes which is provided by java present in java.lang package 
this both follows the Mutable(can be changed) concept 
StringBuilder & StringBuffer contains same methods such as reverse , append etc

by using Builder & Buffer we can modify existing String 
supposed if u want to used this both classes we need to create an Object.

ex : 

StringBuilder sb = new StringBuilder();
StringBuffer sb = new StringBuffer();
