Day 2 Multithreading : 

Thread Class

Thread is a class present in the java.lang package.
To create a thread, we extend the Thread class.
We must override the run() method.
The thread starts when we call the start() method.


Runnable Interface 

Runnable is an interface in java.lang.
We implement Runnable interface.
We override the run() method.
Then we pass the object to a Thread object.
