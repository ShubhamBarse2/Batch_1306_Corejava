
Serialization in java :

serialization is an process where we can converting java objects into ByteStream file. 
the reverse process of serialization is called as Deserialization  

if u want to achieved Serialization we must implements Serializable(java.io) Interface (Marker Interface)

File Handling : 

it is also process where we can performed file Creation , updation , insertion , deletion(read & write) operation on file is called file Handling : 


Serialization   : ObjectOutputStream / FileOutputStrem  / write Operation
DeSerialization : ObjectInputStream  / FileInputStrem   / Read Operation
