String in java : 

1. String is an collection of characters / Sequence of characters 
also it is an built in class which is present in java.lang , no need explicitly import this package (its by default imported) 

2. it is an non-Primitive datatype because it is an Class which is provided by the java 

supposed if u want to store anything so we used string(Numeric value alphabets)ex(Pancard Numbers) 
it contains built in methods like as interns() , toString() , equals()...

3. String is an case- Sensitive : (hello & Hello -> (different))
4. String is an Immutable(cannot be changed)(if we declared any string so we cannot be changed)

5. we can create String by using two ways : 

1> by using String Literals (String name ="Ram")
2> by using Object Creation (String name = new String("Vishal")) --> (Heap)



Immutable  -> cannot be changed 

Mutable -> can be changed
